This project is deployed and live on GitHub Pages!
**View the portfolio here:** [Demo Portfolio](https://professorlegit-66.github.io/demo-portfolio/)

## 📌 Project Overview:

This project is a lightweight, responsive-friendly static webpage designed to showcase core web development fundamentals. It demonstrates how to structure a clean, professional interface using primitive HTML tags and basic CSS styling techniques.

## 🛠️ Tech Stack & Constraints:

* **HTML5:** Semantic structuring and sectioning.
* **CSS3:** Built strictly using the **CSS Box Model** (Margins, Padding, Borders, Width/Height).
* **Layout Constraints:** Advanced layout modules like Flexbox and CSS Grid were intentionally avoided to focus on fundamental positioning techniques like `inline-block` and text alignment.

## ✨ Features:

* **Slate & Indigo Theme:** A professional, modern color palette.
* **Two-Column Layout:** Implemented without Flexbox using carefully calculated `inline-block` containers.
* **Skill Pills & Content Cards:** Stylized UI elements to display technical focus, projects, and certifications.
* **Clean Navigation:** A simple, fixed-style header for easy page routing.

## 🚀 How to Run Locally:

If you want to run this project on your own machine instead of viewing the live link:

1. Clone or download this repository.
2. Extract the files to a local directory.
3. Open the `index.html` file directly in any modern web browser (Chrome, Firefox, Edge, Safari). No server or build process is required.
